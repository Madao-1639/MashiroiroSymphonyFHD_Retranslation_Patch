# 纯白交响曲 FHD 汉化移植

把【绿茶汉化组 × 熊喵守护协会 V1.03】的人工汉化文本移植到 Steam 版[《纯白交响曲 -Love is Pure White-》](https://store.steampowered.com/app/2737970/)，替换官方简体中文内容。

> 本仓库只包含文本移植所需的分析与工具，不包含任何游戏本体文件；补丁仅供已购买正版游戏的用户使用。

## 安装 / 卸载 / 更新

**安装**：
1. 从 [Releases](../../releases) 下载 `CN.xp3`；
2. 把 `CN.xp3` 复制到游戏安装目录，与 `data.xp3`、`patch.xp3` 同级；
3. 启动游戏，在语言选择界面选「简体中文」；
4. 进入游戏即为移植后的文本。

游戏目录一般位于 `<Steam 库>\steamapps\common\MashiroiroSymphonyFHD`（Steam 库中右键游戏 → 属性 → 已安装文件 → 浏览）。

**卸载**：删除游戏目录下的 `CN.xp3`。补丁不改任何官方文件，不需要通过 Steam 验证文件完整性来恢复。

**更新**：用新版 `CN.xp3` 覆盖旧文件即可。

## 实现原理

- 两个版本的剧情不是普通文本文件，而是编译过的脚本。对白夹在脚本里，**一句一个字符串**，所以可以按「哪个脚本 → 哪一段场景 → 第几句」精确定位并替换
- 民汉补丁是明文归档，可直接提取；Steam 版的归档是 Hxv4 加密的，需要先解锁
- 回写时脚本里的 `length` 字段（字符计数）需要重算，否则将影响自动播放/快进的节奏
- 补丁为何能生效：`CN.xp3` 是引擎启动时会自己注册的归档名，钩子在启动流程末尾把 `CN.xp3>cn/scn/` 追加为**最高优先**的搜索路径，于是简中剧情脚本换成移植文本，其余一概不动。

## 已知情况

文本提取、比对、逐句匹配、回写与打包均已完成，简中剧情已换成绿茶汉化组的译文；补丁为**单个新增归档** `CN.xp3`，删除即回滚。

| | 人工汉化补丁 V1.03 | 官方中文 |
|---|---|---|
| 脚本 | 277 个 | 202 个 |
| 对白 | 69,544 条 | 53,218 条 |

范围：

- 两边共有的 **201 个脚本**里，243 段场景的对白条数完全一致，可逐句一一对应，不需要重排段落
- Steam 版**没有**的 76 个脚本不参与移植：SANA EDITION 追加路线 60 个、PSP 版追加的美羽路线 15 个、开发备注 `dummy.txt` 1 个
- 忽略界面词条，只做剧情对白

其他细节：

- 民汉补丁自身有少量未译残留：69,544 行里 **88 行**仍含日文假名，其中 66 行在开发备注 `dummy.txt` 里；落在可移植的 201 个共同脚本中的只有 **14 行**。这些位置不搬民汉文本，保留官方译文或另译。
- 引号风格不同：民汉用 `「……」`，官方用 `“……”`。以民汉为准，回写时统一。
- SANA EDITION / PSP 追加内容不在本补丁范围内：Steam 版 FHD 没有这些路线，民汉对应的译文没有落点。
- 没有成就系统：本作 Steam 版没有成就，不存在「替换文本导致成就失效」的问题。
