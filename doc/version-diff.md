# 两版文本差异

> 状态：**已完成**（2026-10-27）。民汉侧与 Steam 侧都已提取，逐场景对齐结果为「零结构差异」。

## 1. 两版是什么

| | 民汉补丁（绿茶汉化组 × 熊喵守护协会 V1.03） | Steam 版（appid 2737970） |
|---|---|---|
| 母体 | 日文原版 FHD（其中包含 SANA EDITION 追加路线与 PSP 追加路线脚本） | 「Love is Pure White」本体 |
| 文本载体 | 明文 xp3 里的 `*.scn`（`mdf\0` 外壳 + PSB） | Hxv4 加密 xp3 里的裸 PSB（无 `mdf` 外壳） |
| 脚本语言变体 | 单一（中文） | 同一份脚本在 **3 个 Hxv4 domain** 里各存一份：简中 / 繁中 / 英文 |
| 提取结果 | `resource/chs_text/`：277 脚本 / 69,544 对白 / 11 选项 | `resource/steam_text/`：202 脚本 / 53,218 对白 / 11 选项 |

## 2. Steam 侧怎么取到的（结论，可复跑）

Steam 版 xp3 全为 Hxv4 加密。密钥材料只能从运行中的游戏读（静态派生不可用，见
[hxv4.md](hxv4.md) §3），取到后**整条链路离线**：

```bash
mamba run -n GalRev python script/extract_text.py     "<游戏目录>/patch.xp3" "<游戏目录>/data.xp3" "<游戏目录>/data_fhd.xp3"     --profile resource/hxv4/profile_live.json     --domain 9D31BC7AA367A8F1 --out resource/steam_text
```

两个必须知道的取数规则：

1. **`domain` 目录层就是语言维度**。同名脚本在 3 个域各一份（实测 `scenario_01.txt`）：

   | domain | 语言 | 首句 | `patch` 版首句 |
   |---|---|---|---|
   | `BB415FD37CFB564A` | 英文 | `"Ah!"` | `Read the Sana After Story?` |
   | `9D31BC7AA367A8F1` | **简中** | `“啊！”` | `是否观看纱凪的后日谈？` |
   | `9A19D83EC5BE3036` | 繁中 | `「啊！」` | `是否觀看紗凪的後日談？` |

2. **归档优先级 `patch.xp3 > data_fhd.xp3 > data.xp3`**（krkrz 按归档名升序注册、后注册者优先）。
   `scenario_01.txt` 在 `patch` 里比 `data` 多 1 条分支（220 → 221 条）。

## 5. 文本层面的差异（影响匹配与回写）

1. **引号风格**：民汉用 `「……」`，Steam 官方用 `“……”`（繁体为 `「」`）。匹配时应做归一化，
   回写时决定保留哪一套（建议保留民汉风格，与译文一致）。
2. **`text_plain` 字段**：民汉脚本 20,721 处对白有 5 元分页（`text` + 去换行的 `text_plain`），
   Steam 脚本**全部是 3 元分页**（只有 `text`）。回写时只需写 `text` 与 `length`，
   不必生成 `plain`；如果沿用民汉的 5 元结构则需自己补 `plain`。
3. **民汉补丁自身有少量未译残留**：69,544 行里 **88 行**仍含日文假名，其中 66 行在开发备注 `dummy.txt`（不参与移植），落在 201 个共同脚本里的只有 **14 行**，散布在 13 个脚本中。
   这些行不搬民汉文本，保留官方译文或另译。Steam 侧只有 11 条含假名（人名、拟声），属正常。
4. **控制码与 `length` 口径**：民汉文本里夹 `%NNN;`（角色/特效标记）、`#RRGGBBAA;`（着色）、
   `#;`（复位）、`\k`/`\p`（等待标记），`\n` 是字面两字符。Steam 侧同一套标记都在，但
   **`length` 字段的算法不同**：官方把标记排除在计数外（84 页可证），民汉把标记也算进去。
   回写时统一用 `tool/scn.py::page_length()`，详见 [text-model.md](text-model.md) §2.2。

## 6. 对匹配阶段的建议（交接）

1. 主键用 `(script, scene, row, page)`，覆盖率已达 100%，不需要模糊对齐；
2. 先按第 5.3 条标出民汉的 14 行日文残留，避免把日文灌进 Steam；
3. 引号/标点归一化后再做相似度校验（防止 row 顺序在个别脚本里错位——虽然计数全对，
   仍建议抽 5% 做语义核对）；
4. 移植后每一条都要重算 `length`（UTF-16 码元数），见 [text-model.md](text-model.md) §4。

详细逐脚本对照见 [version-diff-report.md](version-diff-report.md)（由 `script/diff_versions.py` 生成）。
